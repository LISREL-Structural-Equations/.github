# LISREL — Path fit on a structural file you own

LISREL keeps one named path board on the desk: the live equations, the fit step in front of you, and a short note the next revision can read. Extra models wait for their own title.

## Session Card

| Slice | What you do in LISREL | What remains |
|-------|------------------------|--------------|
| Arrival | Open LISREL and name today's path file | A titled structural job |
| Focus | Keep only live paths on the LISREL board | A short equation list |
| Check | Read the LISREL fit before a large change | A confirmed measurement set |
| Handoff | Mark finished passes inside LISREL | A note for the next revision |

## How LISREL Sits

LISREL sits beside the paper diagram and the files you already keep. It does not replace them. It is a named research file for one path job you own: which structural equations are open, which measurement model is pinned, and what the next pass should read. A local LISREL profile is enough for everyday fit work.

If two people share a PC, each keeps a LISREL style of their own. The path board stays small on purpose. Extra models wait for their own title instead of crowding the live diagram. A first visit should be one short fit pass, then the same LISREL file the next day.

## Traffic Light

| Signal | On the LISREL board | What you do |
|--------|----------------------|-------------|
| Green | Named path, short equation list | Continue the same fit pass |
| Amber | Paths from two files mixed | Split the set before a large change |
| Red | No title, indices with no diagram | Stop and name the LISREL file first |
| Clear | Handoff written, paths few | Close LISREL and leave the research file |

## Open Order

1. Open the last LISREL session, not a new empty path file.
2. Read the equation list and the last handoff.
3. Finish one visible fit step inside LISREL.
4. Write what changed, then close with fewer loose indices than you found.
5. If the set feels crowded, drop anything that belongs to a different LISREL model.

## After a Week

A week of LISREL revisions keeps the same path file, with fewer loose indices. It is the same title, a shorter equation list, and a note that still makes sense on Monday.

Other programs stay where they are. LISREL only keeps the path back: file name, equations, fit, handoff. Leave LISREL with a quieter research file than the one you opened. The next visit should start on that file, not in a search.

## Sign-off

- [ ] The LISREL file name is short enough to scan
- [ ] Only live paths you own are on the board
- [ ] A second person can read the handoff
- [ ] The last LISREL session still opens after a restart
- [ ] Finished models are off the live LISREL set
- [ ] The LISREL fit still matches the diagram on the board
- [ ] The path diagram still matches the last LISREL pass

## Field Note

LISREL reads better when the path diagram still matches the equations on that pass. Name the file, keep the live structural set, finish one visible fit, and write what changed. Extra models wait for their own title.

The same loop fits a measurement model, a path revision, or a shared computer. Open the last LISREL session and continue. Do not rebuild the diagram from scratch.
